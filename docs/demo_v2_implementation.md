本文档记录当前 Godot Demo 已经实现的功能、主要规则和维护入口。当前主入口是：

`res://scenes/skill_build_scene.tscn`

核心数据文件：

`res://data/demo_data.json`

## 整体流程

1. 进入技能拼图系统。
2. 在技能卡页调整模组。
3. 在角色页给角色装备技能卡。
4. 点击左上角【进入地图】进入战斗准备/探索流程。
5. 在地图中按 7 步路线选择节点。
6. 战斗节点进入 PVE 搜打撤战斗。
7. 战斗胜利后获得金币、模组或遗物奖励。
8. 可返回构筑调整、继续探索、进入商店、开宝箱、使用火堆或挑战 Boss。

- 技能卡能量规则显示。

### `scripts/battle_runtime.gd`

负责场景之间的数据保存和战斗数据生成，是构筑系统、地图和战斗之间的桥。

已实现：

- 作为 Autoload 单例保存构筑状态。
- 从 JSON 读取静态数据。
- 保存技能卡模组摆放状态。
- 保存角色装备技能卡状态。
- 根据拼图结果生成战斗技能数据。
- 计算技能能量消耗。
- 计算特殊格加成。
- 生成战斗用角色运行时数据。
- 生成技能效果摘要。
- 生成统一的模组形状文本。
- 保存探索状态：探索步数、当前节点、士气、金币、商店状态、Boss 是否击败。
- 保存运行时模组库存。
- 保存队伍快照：角色生命、重伤、死亡。
- 进入战斗前创建临时战斗回档点，支持重进本战。
- 保存已获得遗物，并提供遗物池抽取接口。

重要函数：

- `import_builder_state(...)`：构筑页进入战斗前调用，保存当前构筑。
- `generate_skill_for_card(card_index)`：把技能卡拼图转换成技能数值。
- `build_character_runtime(character_index)`：生成战斗用角色数据。
- `skill_effect_summary(skill)`：生成技能效果摘要。
- `module_shape_text(shape, size)`：生成模组形状文本。
- `start_exploration()`：初始化一轮探索。
- `advance_exploration(node_type)`：推进地图节点。
- `create_battle_checkpoint()` / `restore_battle_checkpoint()`：战斗前存档和回档。
- `roll_shop_offers()`：刷新商店商品。
- `roll_relic_choices(count)`：从剩余遗物池抽取候选。

## 战斗流程

### 1. 进入战斗

进入战斗后：

- 我方 3x3 半场为空。
- 角色全部在待部署区。
- 第一回合开始时获得 6 点能量。
- 之后每回合开始时获得 3 点能量。
- 能量上限为 10。
- 如果遗物在上回合末提供了下回合能量奖励，会在回合开始额外获得。

### 2. 准备阶段

准备阶段可以：

- 部署角色。
- 撤退角色。
- 点击【开始战斗阶段】。
- 回档重进本战。

部署规则：

- 点击待部署区角色按钮。
- 我方 3x3 空格高亮。
- 点击空格部署角色。
- 部署消耗 2 点能量。
- 同一回合撤退后的角色不能再次部署。

撤退规则：

- 只能在准备阶段撤退。
- 撤退角色回到待部署区。
- 撤退返还 1 点能量。
- 撤退角色本回合不能再次部署。
- 撤退后清除该角色所有 buff 和 debuff。
- 待部署/撤退角色在回合结束时恢复 5% 最大生命。

### 3. 战斗阶段

战斗阶段开始后：

1. 计算所有在场单位当前速度。
2. 根据速度生成行动队列。
3. 单位依次行动。
4. 速度相同时，我方优先。
5. 同阵营同速时按行列顺序排序。

我方行动：

- 普攻某一行，攻击该行敌方最前方单位。
- 使用当前角色自己装备的技能。
- 防御：下次受到伤害降低 30%，与其他减伤乘算，受击后解除。
- 移动：点击后高亮相邻格。目标格为空则移动，有我方单位则交换位置。移动后结束本次行动。
- 技能消耗来自 `BattleRuntime.generate_skill_for_card(...)`。
- 士气低于 40 时，我方技能能量消耗 +1。

敌方行动：

- 药师优先治疗受伤敌人，否则进行默认攻击。
- 弩手优先攻击我方后排血量最低单位。
- 火油投手攻击目标所在行的所有我方单位，按 100% 力量计算。
- 刺客突袭血量比例最低的我方单位，造成 115% 力量伤害，并有 30% 穿透。
- 恐吓者造成伤害并降低我方 4 点士气。
- 战鼓头目为敌方全体提供护盾和速度。
- 邪术军师施加寒冷和易伤。
- 盗匪首领横扫我方最靠前的一列。士气低于 40 时，作为自身特性造成 135% 力量伤害。
- 召唤师有空格时放置召唤标记，无空格时攻击我方最靠前的一列。
- 普通近战优先攻击同一行最靠前的我方单位。

### 4. 结束阶段

行动队列清空后进入结束阶段。

结束阶段顺序：

1. 结算灼烧等层数状态。
2. 护盾衰减。
3. 持续状态倒计时。
4. 技能 CD 减少。
5. 撤退/待部署角色恢复生命。
6. 判断是否已经胜利，若胜利则直接结束。
7. 触发遗物的回合结束效果。
8. 按当前回合数降低士气：第 X 回合结束时士气 -X，但单次最多降低 5 点。
9. 如果场上没有我方角色，额外士气 -40。
10. 士气为 0 时探索失败。
11. 进入下一回合准备阶段。

## 士气系统

初始士气：80。

当前规则：

- 士气大于等于 80：我方全队速度 +2。
- 士气小于 40：我方全队速度 -2，技能能量消耗 +1。
- 士气降到 0：探索失败。
- 我方角色重伤时士气 -25。
- 第 X 回合结束后士气 -X，但每回合结束最多因此降低 5 点士气。
- 回合结束时如果场上没有我方角色，士气额外 -40。
- 普通战胜利士气 +10。
- 精英战不再击败单个敌人获得士气，敌方全灭后士气 +15。

士气相关模组：

- 鼓舞模块可以提升士气。
- 士气打击会消耗士气，并入本技能总伤害一起结算。
- 士气护盾会消耗士气，并入本技能总护盾一起结算。
- 如果士气不足，对应士气消耗模块不触发，其他基础效果仍正常结算。

当前士气消耗模块：

- 士气打击：消耗 5 士气，并入本技能伤害：+60% 力量伤害。
- 士气打击+：消耗 7 士气，并入本技能伤害：+78% 力量伤害。
- 士气护盾：消耗 3 士气，并入本技能护盾：+75% 意志护盾。
- 士气护盾+：消耗 5 士气，并入本技能护盾：+98% 意志护盾。

## 状态系统

当前主要 buff/debuff：

- 加速：提高速度，持续回合数。
- 稳固：受到伤害降低，持续回合数。
- 防御：下次受到伤害 -30%，受击后解除。
- 易伤：1 层受到伤害 +25%，每多 1 层额外 +5%，回合结束层数 -1。
- 虚弱：1 层造成伤害 -20%，每多 1 层额外 -5%，最多 10 层，10 层为 -65%，回合结束层数 -1。
- 灼烧：回合结束受到层数对应伤害，然后层数 -1。
- 寒冷：速度降低，达到 5 层转化为冻结。
- 冻结：跳过下次行动；冻结角色无法再获得寒冷。

显示规则：

- 格子内只显示短摘要，例如 `状态：加速1，稳固2`。
- 鼠标悬浮单位时显示完整状态效果说明。
- 敌人悬浮信息显示属性、攻击方式、特殊特性和状态。

伤害结算：

- 统一在 `_apply_damage(...)` 中处理。
- 虚弱、稳固、防御、易伤等倍率先合并成一个式子，最后只四舍五入一次。
- 穿透在最终伤害基础上拆分护盾穿透伤害和普通伤害。

## 技能逻辑

### 精准打击

- 射手技能。
- 点击技能后进入敌方目标选择。
- 点击某个敌方角色后，对该目标造成单体伤害。

### 横扫

- 战士技能。
- 范围技能能量规则：`1 能量=1-3 格，2 能量=4-6 格，3 能量=7-9 格`。
- 点击技能后立刻攻击敌方第一列所有存活单位。
- 敌方第一列就是敌方前排。

### 守护祷言

- 牧师技能。
- 使用范围技能能量规则。
- 点击技能后进入我方目标选择。
- 点击一名我方角色后，该角色作为中心目标。
- 中心目标以及上下左右相邻我方角色都会获得完整技能效果。
- 可以提供治疗、护盾、士气等效果。

### 战术支援

- 坦克/战士可用技能。
- 影响自身和上下左右相邻友方。
- 可以提供护盾、加速、减伤等效果。

### 灼烧打击

- 根据相邻伤害模组施加灼烧。
- 灼烧层数 = 相邻伤害模组直接伤害总和 × 系数。
- 灼烧打击系数为 0.5。
- 灼烧打击+ 系数为 0.65。
- 灼烧打击和灼烧打击+ 都是 1x1。
- 初始模组中拥有 1 张灼烧打击。

- 高血量角色尽量站在前排。

### Boss 战

Boss 为召唤师。

初始敌人：

- 中路前排：精英盾卫。
- 中路后排：召唤师。
- 右下角：盗匪药师。

召唤师数据：

- HP 200
- 力量 10
- 意志 10

召唤师规则：

- 如果有空余格子，行动时放置召唤标记。

- 偶数回合召唤精英战敌人。
- 准备阶段开始时，如果召唤师未死亡，标记变为召唤出的敌人。
- 有 50% 概率选择第一列空格，有 50% 概率选择第二/三列空格。
- 第一列无空格时，必定在第二/三列召唤。
- 第一列召唤前排敌人，第二/三列召唤后排敌人。
- 召唤师死亡后立刻获得胜利，其余敌人会被清除。
- 如果没有空余格子，召唤师攻击我方最靠前的一列。

## 奖励与探索

战斗奖励：

- 普通战胜利：15 金币，白色模组奖励。
- 精英战胜利：30 金币，先选 1 个绿色模组，再选 1 个遗物。
- Boss 战胜利：50 金币，探索通关。
- 战斗胜利后，所有存活角色恢复 15% 最大生命值。

宝箱奖励：

- 从绿色模组池中抽取候选。
- 玩家选择 1 个加入库存。

精英战遗物奖励：

- 从剩余遗物池随机抽 3 个遗物呈现。
- 玩家选择 1 个获得。
- 每个遗物只能获得 1 次。
- 已获得遗物不会再次出现。

当前遗物：

- 空袋电池：回合结束时若能量为 0，下回合开始额外 +1 能量。
- 满格电池：回合结束时若能量不为 0，下回合开始额外 +1 能量。
- 满员旗帜：回合结束时若我方未死亡人数 ≥4，士气 +4。
- 残队徽章：回合结束时若我方未死亡人数 <4，士气 +3。

- 技能装配页只显示已拥有模组。
- 技能预览摘要显示合并后的士气伤害/护盾。
- 战斗奖励、宝箱、商店显示模组形状和效果。

交互提示：

- 鼠标悬停我方或敌方角色格子，显示角色当前属性信息。
- 鼠标悬停敌人，显示攻击方式和特殊特性。
- 轮到角色行动时，鼠标悬停技能按钮，显示技能信息。
- 目标选择时只改边框，不覆盖角色文字 UI。

## 维护注意点

### 1. `phase` 是战斗状态机核心

常见值：

- `prepare`：准备阶段。
- `battle`：战斗队列推进中。
- `player_action`：等待玩家选择角色行动。
- `target_enemy`：等待玩家选择精准打击目标。
- `target_ally`：等待玩家选择守护祷言目标。
- `move_target`：等待玩家选择移动目标格。
- `reward_select`：等待选择奖励。
- `choice`：等待探索结束或继续深入。
- `demo_end`：Demo 结束。

新增功能时，优先确认它应该发生在哪个 `phase`。

### 2. 战斗单位是 Dictionary

常见字段：

- `name`
- `team`
- `role`
- `row`
- `col`
- `hp`
- `max_hp`
- `shield`
- `strength`
- `will`
- `speed`
- `field`
- `dead`
- `retreated`
- `injury_marks`
- `status_effects`
- `layered_statuses`
- `equipped_skills`
- `skill_cooldowns`

项目把 Warning 当 Error，读取 Dictionary 字段时经常需要显式类型转换：

```gdscript
var damage: int = int(unit["strength"])
var speed: int = int(unit["speed"])
```

### 3. 技能数值不要在战斗里写死

战斗中使用技能时，应优先读取：

```gdscript
BattleRuntime.generate_skill_for_card(...)
```

或者角色运行时数据中的：

```gdscript
unit["equipped_skills"]
```

这样技能拼图和模组调整才会真正影响战斗。

### 4. 模组形状文本要用统一函数

需要显示模组形状时，优先使用：

```gdscript
BattleRuntime.module_shape_text(module["shape"], module["size"])
```

这样技能构筑页、战斗奖励、地图宝箱、商店的显示格式会保持一致。

### 5. UI 大多是动态重建

战斗场景里的棋盘和按钮大多由代码动态生成。

主要刷新入口：

```gdscript
_refresh()
```

主要 UI 重建函数：

```gdscript
_rebuild_grid(...)
_clear_action_buttons()
_add_action_button(...)
```

修改交互时，注意不要让旧按钮残留在 `actions_row` 中。
