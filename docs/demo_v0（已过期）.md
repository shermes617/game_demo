# Demo V0 已实现功能说明

本文档描述 `demo_v0` 场景当前已经落地的功能，方便后续继续扩展战斗、角色成长和可视化界面。

## 1. 当前 Demo 的定位

当前 `demo_v0` 已经实现为一个“技能卡构筑 + 角色装备”的前置原型，而不是完整战斗 Demo。

当前工作流分为两个页面：

1. `技能卡` 页面
   - 先选择技能卡
   - 再选择模组并装配到技能卡上
   - 实时查看技能效果、能量消耗和特殊格触发情况
2. `角色` 页面
   - 查看角色属性
   - 选择角色
   - 给角色装备符合职业限制的技能卡

## 2. 场景与结构

### 2.1 场景骨架

`demo_v0.tscn` 已经不是纯代码生成页面，而是具有固定区域节点的场景骨架。

主要区域：

- 顶部标题区
- 页面切换区
  - `技能卡`
  - `角色`
- 左侧列表区
  - 主列表
  - 次级列表
- 中间工作区
  - 技能卡装配工作区
  - 角色装备工作区
- 右侧预览区
- 底部操作与状态区
- 鼠标跟随模组预览层

这样后续如果要继续加：

- 技能卡详情面板
- 角色立绘区
- 装备槽位显示
- 战斗前确认按钮

都可以直接在场景里扩节点，而不是继续把所有 UI 写死在脚本里。

## 3. 技能卡页面已实现功能

### 3.1 技能卡独立于角色

当前技能卡不再预绑定角色。

技能卡现在是单独构筑对象，玩家可以先完成技能卡拼图，再在角色页决定把哪张卡装备给哪个角色。

### 3.2 技能卡选择

左侧主列表可以切换当前编辑的技能卡。

当前数据中已配置的技能卡：

- `精准打击`
- `守护祷言`
- `横扫`
- `战术支援`

### 3.3 模组库存与装配

左侧次级列表显示所有模组库存。

已实现：

- 点击模组选中
- 显示当前库存数量
- 所有技能卡共享模组库存
- 库存耗尽后禁用对应模组按钮

### 3.4 棋盘放置规则

中间棋盘支持以下规则：

- 根据技能卡形状显示可用格子
- 不可用格子禁放
- 超出边界禁放
- 模组重叠禁放
- 独行模组限制
  - 每张技能卡最多一个独行模组
- 右键移除已放置模组

### 3.5 模组旋转与鼠标预览

已实现直观的装配预览：

- 选中模组后，鼠标位置显示当前模组形状
- 鼠标在形状左上角
- 按 `R` 键可顺时针旋转
- 点击按钮也可旋转
- 旋转后鼠标预览会实时更新

### 3.6 默认构筑与清空

已实现：

- 清空当前技能卡
- 恢复默认推荐构筑

默认构筑数据来自 JSON，而不是写死在脚本里。

### 3.7 实时技能生成

当前技能卡在装配过程中会实时生成结果。

已计算内容包括：

- 作用对象
- 能量消耗
- 占用格数
- 伤害百分比
- 治疗百分比
- 护盾百分比
- 穿透
- 士气收益
- 加速
- 减伤
- 对护盾目标额外效果

### 3.8 特殊格加成

已实现技能卡特殊格对模组的加成判定。

当前支持：

- 伤害加成格
- 治疗加成格
- 护盾加成格
- 辅助持续时间格
- 护盾目标额外伤害格

### 3.9 能量消耗规则

已实现根据技能卡类型按占用格数计算能量。

当前支持两种曲线：

- `single`
  - 单体类技能卡
- `range`
  - 范围类技能卡

## 4. 角色页面已实现功能

### 4.1 页面切换

点击顶部 `角色` 按钮后，可进入角色装备页。

### 4.2 角色选择

左侧主列表显示所有角色。

当前数据中已配置角色：

- 战士
- 射手
- 坦克
- 牧师

### 4.3 角色属性展示

中间角色工作区已显示：

- 角色名称
- 职业名称
- 角色定位
- 力量
- 生命
- 意志
- 速度

### 4.4 技能卡职业限制

技能卡已支持职业限制字段：

- `allowed_professions`

角色已支持职业字段：

- `profession`
- `profession_name`

当前角色装备页中：

- 只显示并允许点击当前职业可使用的技能卡
- 不符合职业限制的技能卡会被禁用
- 装备按钮会再次做职业合法性校验

### 4.5 角色装备技能

当前角色页已实现：

- 为角色装备选中的技能卡
- 如果已装备则变为卸下
- 清空当前角色全部技能装备
- 显示当前角色已装备的技能卡列表
- 同一张技能卡可以被多个角色装备

### 4.6 技能槽数量限制

角色数据中已支持：

- `allowed_card_slots`

当前默认每个角色 1 个技能槽。

如果以后要扩成 2 个技能槽，可以直接改数据和少量 UI 文案。

## 5. 当前预览区已实现内容

右侧预览区当前会围绕“当前选中的技能卡”显示：

- 职业限制
- 作用对象
- 当前能量
- 当前占用格数
- 技能数值效果
- 特殊格触发情况
- 模组摘要

在角色页中，还会额外显示：

- 当前角色是否允许装备这张技能卡

如果继续在当前架构上推进，推荐顺序如下：

1. 在角色页加入明确的技能槽 UI

3. 新建战斗场景，读取角色已装备技能卡数据
4. 将 `generate_skill_for_card` 的结果作为战斗技能输入
